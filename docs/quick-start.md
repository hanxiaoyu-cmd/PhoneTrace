# 快速上手

[返回首页](../README.md) · [了解指标和准确性](accuracy.md)

PhoneTrace 在电脑上运行，手机正常运行游戏。你不需要安装 Python、手机端 APK 或获取 Root；便携版已包含运行库和 ADB。

## 1. 打开软件

从项目首页的发布版本链接下载 Windows x64 便携包，**先完整解压**，再双击 `PhoneTrace/PhoneTrace.exe`。请保留整个 `PhoneTrace` 文件夹；只复制 EXE 会缺少运行库。

没有手机在身边时，勾选“演示模式”即可体验界面、保存和历史回看。演示记录明确标注为模拟，不可用于评价手机性能。连接真机开始测试前，请取消演示模式。

## 2. 用 USB 连接手机

1. 手机打开开发者选项。小米系统通常位于“设置 → 我的设备 / 关于手机 → 详细信息与规格”，连续点击系统版本；不同版本菜单名称可能不同。
2. 在开发者选项中打开 **USB 调试**。
3. 使用支持数据传输的 USB 线连接电脑，在手机上确认允许这台电脑调试。
4. 软件点击刷新，选择状态在线的设备。

如果手机显示未授权，请解锁手机并确认调试授权弹窗。如果系统提示权限不足，且提供“USB 调试（安全设置）”，可按系统引导启用。

## 3. 选择游戏并记录

1. 手机打开游戏，进入实际游戏场景。
2. 软件点击 **识别前台**，确认包名属于要测试的游戏，也可以在列表中选择或手动输入。包名形式如 `com.tencent.tmgp.sgame`。
3. 保持游戏图层“自动识别”，填写测试标题，默认使用 **0.5 秒**采样间隔。
4. 点击 **开始记录**。可设置时长自动结束，也可手动点击 **停止并保存**。
5. 在 **测试记录** 中打开历史测试，或打开记录文件夹查看 CSV 和 HTML 报告。

如果 FPS 显示 `—`，进入游戏中的活动场景，再刷新图层并选择与游戏对应的 `SurfaceView` 或 `BLAST` 图层。不要选择导航栏、壁纸、游戏助手或悬浮窗图层。系统禁止访问时间戳时，手动选择图层也可能无法获取 FPS。

## 4. 记录功耗估计：无线连接后拔线

USB 连接会改变供电状态。PhoneTrace 在检测到外部电源时不会把电池净充放电换算为游戏整机功耗，其余可用指标仍会继续记录。

Android 11+ 的系统无线调试可按以下步骤连接：

1. 手机和电脑连接同一局域网。
2. 手机开发者选项打开 **无线调试**，进入 **使用配对码配对设备**。
3. 在软件 **连接手机** 页面填写该弹窗里的 `IP:配对端口` 和六位配对码，点击配对。
4. 关闭手机的配对码弹窗，回到无线调试主页面。将这里显示的 `IP:连接端口` 填入软件连接栏，再点击连接。
5. 刷新设备，选中无线连接的设备。连接成功后拔掉 USB 线，再开始测试。

**配对端口和连接端口通常不同。** 手机重启、无线调试重开或网络变化后，连接端口可能改变，需要重新连接。

即便成功无线连接，系统仍可能禁止读取电流或电压。此时功耗显示 `—`，原始记录保留原因；软件不会编造数据。功耗估计的适用范围见 [准确性说明](accuracy.md#功耗为什么叫估计)。

## 保存在哪里

默认在软件旁边的 `records` 目录。如果程序目录不可写，改为 `%LOCALAPPDATA%/PhoneTrace/records`。界面显示实际保存位置，并提供打开文件夹入口。

每次测试单独一个文件夹，包含 `samples.csv`、`samples.jsonl`、`frame_intervals.csv`、`metadata.json`、`summary.json` 和 `report.html`。CSV 可用 Excel 打开，HTML 报告可用浏览器离线打开。

断连后软件会重试，连续三次读取失败会结束并保留已写入数据。停止后生成报告可能需要几秒；关闭正在记录的窗口时，会先停止并保存。

## 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 设备列表为空 | 数据线是否支持传输、USB 调试是否开启、电脑是否识别设备及安装所需驱动 |
| 设备显示未授权 | 解锁手机，在调试授权弹窗中允许这台电脑 |
| 无线配对成功但连不上 | 是否使用了无线调试主页面的连接端口，而非配对端口；手机和电脑是否在同一局域网 |
| FPS 没有值 | 游戏是否处于活动场景、包名和图层是否正确、系统是否允许读取呈现时间戳 |
| 功耗没有值 | 是否仍在充电、是否确认正在放电、系统是否允许读取电池电流与电压 |
| CPU 或内存为空 | 系统权限是否允许；内存每 5 秒采样，其他采样行按设计留空 |
| 曲线有断点 | 对应时间没有有效数据或发生采集间断；断点不会被当作零值或连接成连续曲线 |
| 与其他工具数值不同 | 先比较图层、统计区间、帧率口径和功耗来源，再比较数值 |

## 做可比较的测试

固定室温、屏幕亮度、游戏画质、帧率上限、性能模式和游戏路线。对比时保持相近的初始电量和温度；额外录屏、插帧和散热背夹会改变条件，应单独记录。不要仅凭一次短测试判断两台手机的整体表现。

当前版本尚未完成真机验证。若愿意反馈适配情况，请附手机型号、系统版本、软件版本、连接方式、游戏包名及记录中的警告信息。
